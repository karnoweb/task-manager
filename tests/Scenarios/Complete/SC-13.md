# SC-13 — پایان کمپین صدعضوی

هدف تجاری: پایان کمپین صدعضوی. [فایل اجرایی مستقل](Scenario13CampaignTest.php)؛ Namespace (فضای نام) `Karnoweb\TaskManager\Tests\Scenarios\Complete`. تمام useها و داده‌های پایه در همین فایل و کلاس پایه صریح آن آمده‌اند.

## وضعیت اولیه و پیش‌نیاز

صد عضو و پنج واگذاری فعال؛ ledger نمونه SQLite، نه سنجش بار PostgreSQL. Laravel 13 و SQLite اختصاصی تست؛ هیچ داده محصول استفاده نمی‌شود. وابستگی تجاری بیرونی برای این جریان لازم نیست؛ fixture میزبانِ قراردادها در کلاس پایه نصب می‌شود.

## مراحل و تغییر داده

| مرحله | ورودی، رفتار و نتیجه مورد انتظار |
|---|---|
| 1 | گذشت ۶۰ ثانیه: ۱۲ رخداد SLA |
| 2 | بستن کمپین و preview: ۷۵ failed، ۱۵ continued و ۱۰ already_terminal |
| 3 | اجرای closure و پردازش دسته‌های ۲۰تایی؛ نتایج دقیق حفظ می‌شوند |
| 4 | ۷۵ علت campaign_ended و ۱۰۰ group_item_processed |
| 5 | پنج واگذاری active و مبدأ waiting باقی می‌مانند؛ اجرای دوباره run هیچ رخداد اضافه نمی‌سازد |

## مجوز و زمینه

زمینه از helper صریح کلاس پایه در فایل PHP ساخته می‌شود؛ فهرست capabilities (توانایی‌های مجاز) در همان manager/context قابل بررسی است. SC-01 و SC-14 مسیر جدید هویت معتبر را نیز اجرا می‌کنند. Actor (اجراکننده)، مالک و مسئول یکی فرض نشده‌اند. نسخه ورودی از رکورد مرتبط خوانده می‌شود؛ Task و Instance نسخه مستقل دارند.

## رکوردها و رویدادها

tm_group_operation_items، tm_outbox، tm_handoffs، tm_workflow_instances، tm_stage_visits. فرمان موفق در تراکنش، journal (دفتر فرمان) و ممیزی/Outbox ثبت می‌شود؛ Query و ساخت زمینه فرمان تازه تولید نمی‌کنند. این سناریو فقط نام رویدادهایی را ادعا می‌کند که در کد زیر بررسی شده‌اند؛ ارسال بیرونی واقعی شبکه انجام نمی‌شود.

## شکست، بازگشت تراکنش و اجرای مجدد

تفکیک شکست تجاری failed از شکست زیرساخت؛ خروجی عمداً ۷۵ failed است و آزمون موفق محسوب می‌شود؛ بار و قفل سرور در این مأموریت تأیید نشده است. هر فرمان تغییر داده، عملیات مستقل دارد؛ تکرار همان شناسه با همان ورودی باید نتیجه قبلی را بدهد و ورودی متفاوت تعارض است. مسیرهای خاص تکرار فقط در جاهایی ادعا شده‌اند که در همین PHP assert (بررسی شرط) دارند. تست‌های منبع و ۲۳۶ تست TM حذف نشده‌اند؛ [نگاشت](../COVERAGE-MAPPING.md).

## خروجی‌های بررسی‌شده

بررسی‌های واقعی این جریان از فایل PHP، برای خواندن دقیق مقادیر قبل/بعد:

```text
self::assertSame(12, $this->sla()->run($this->manager(), 100)['events']);
self::assertSame(100, $preview['total']);
self::assertSame(['failed' => 75, 'continued' => 15, 'already_terminal' => 10, 'manual_review' => 0, 'denied' => 0], $preview['counts']);
self::assertSame(['already_terminal' => 10, 'continued' => 15, 'failed' => 75], $report['counts']);
self::assertSame(75, DB::table('tm_group_operation_items')->where('result', 'failed')->where('reason_code', 'campaign_ended')->count());
self::assertSame(100, DB::table('tm_outbox')->where('action', 'group_item_processed')->count());
self::assertSame('active', $this->handoffs()->get($this->manager(), $handoff['handoff_key'])['status']);
self::assertSame('waiting', DB::table('tm_workflow_instances')->where('id', $handoff['origin_id'])->value('lifecycle'));
self::assertSame('active', DB::table('tm_workflow_instances')->where('id', $handoff['destination_id'])->value('lifecycle'));
self::assertSame('paused', $this->sla()->get($this->manager(), $handoff['paused_visit_id'])['sla_state']);
self::assertSame(['processed' => 0, 'state' => 'complete'], $this->groupService()->process($this->manager(), $run['run_key']));
self::assertSame($run, $this->groupService()->executeClosure($this->manager(), $preview, 'campaign-close'));
self::assertSame($events, DB::table('tm_outbox')->count());
```

## اجرا و نتیجه واقعی

از ریشه مخزن و با TM_TEST_DRIVER=sqlite:

```powershell
$env:TM_TEST_DRIVER='sqlite'
php vendor/phpunit/phpunit/phpunit tests/Scenarios/Complete/Scenario13CampaignTest.php
```

اجرا در ۲۰۲۶-۱۰-۲۳: موفق در SQLite، همراه کل ۱۵ سناریو (۱۶ آزمون، ۱۷۱ بررسی). نتیجه نهایی و شمار اجرای کامل در [راهنمای آزمون](../../../docs/testing.md) ثبت می‌شود. این موفقیت تأیید PostgreSQL/MySQL/MariaDB نیست.
