# E2E-06 — ارجاع موازی حقوقی و ریسک

دو مسیر مستقل با شرط پایان هر دو؛ تأیید کامل با لغو یکی از مسیرها متفاوت است. نسخه قدیمی اجازه بازنویسی تغییر مسیر دیگر را ندارد.

دو مجموعه داده مستقل اجرا می‌شوند.

فایل اجرایی: tests/EndToEnd/E2E06Test.php

اجرای مستقل: php vendor/bin/phpunit tests/EndToEnd/E2E06Test.php

شواهد فعلی: docs/phase3-e2e-postgres.xml و گزارش کامل docs/phase3-all-postgres.xml.

این شواهد مربوط به جریان سمت سرور با میزبان آزمایشی واقعی است. تأیید اتصال محصول تجاری و رابط کاربری و پذیرش نهایی فاز هفت جداگانه لازم است.
