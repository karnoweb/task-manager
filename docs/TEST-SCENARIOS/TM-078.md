# TM-078 — ارسال رویداد پس از ثبت قطعی

- پیش‌شرط: پایگاه‌دادهٔ اختصاصی آزمون با ساختار تازه؛ کاربر a در قلمرو one.
- اجرا: فایل متناظر tests/Scenarios/TM078Test.php؛ داده‌ها و شناسه‌های فرمان داخل همان آزمون صریح‌اند.
- مراحل و انتظار: در تراکنش بیرونی کار ساخته می‌شود؛ ارسال پیش از commit باید dispatch_before_commit بدهد. پس از commit فقط یک رویداد باید تحویل شود.
- امنیت: هویت و قلمرو صریح؛ دادهٔ میزبان واقعی ساخته یا تغییر داده نمی‌شود.
- پاک‌سازی: ساخت مجدد ساختار پایگاه‌داده پیش از سناریوی بعدی.
- شواهد: گزارش JUnit در docs؛ وضعیت فقط از اجرای واقعی خوانده شود.
