# TM-166 — ارجاع با توقف مبدأ و مقصد مستقل

این آزمون مستقل مربوط به فاز ۳ است؛ نتیجهٔ نهایی فاز ۷ محسوب نمی‌شود.

پیش‌نیاز: پایگاه‌دادهٔ اختصاصی آزمون، میزبان آزمایشی با مجوز صریح، ساعت کنترل‌شده و دو مسیر فروش و قرارداد. دادهٔ محرمانه در میزبان می‌ماند.

مراحل و انتظار دقیق در بدنهٔ اجرایی زیر مشخص است. هر فرمان با نسخه و شناسهٔ عملیات اجرا می‌شود؛ نتیجه، وضعیت، تاریخچه یا تعداد اثرها بررسی می‌شود. شکست هر انتظار آزمون را ناموفق می‌کند.

اجرا: `php vendor/bin/phpunit --filter TM166Test`. آزمون هم‌زمانی TM-175 فقط روی PostgreSQL واقعی اجرا می‌شود؛ کنارگذاری آن در SQLite قبولی نیست.

```php
public function test_tm166(): void
    {
        [$h, $origin, $destination] = $this->delegateFixture();
        $waiting = $this->instances()->get($this->manager(), $origin['instance_key']);
        self::assertSame('waiting', $waiting['lifecycle']); self::assertSame('new', $waiting['current_state_key']);
        self::assertSame('active', $destination['lifecycle']); self::assertSame('contracts', $destination['slot_key']);
        self::assertNotNull($this->sla()->get($this->manager(), $h['paused_visit_id'])['paused_at']);
        self::assertCount(1, $this->instances()->visits($this->manager(), $origin['instance_key']));
        self::assertSame($waiting['case_id'], $destination['case_id']);
        $this->expectExceptionMessage('instance_on_hold');
        $this->instances()->transition($this->manager(), $origin['instance_key'], 2, 'bypass', 'review');
    }
```

فایل اجرایی: `tests/Scenarios/TM166Test.php`. پشتیبان داده و سیاست: `tests/HandoffTestCase.php`. برای آزمون حدنصاب، سه مقصد مستقل با سیاست اعلام‌شده ساخته می‌شود؛ برای مسئول، هر سه حالت با دادهٔ جداگانه اجرا می‌شود.
