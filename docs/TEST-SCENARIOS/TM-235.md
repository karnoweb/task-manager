# TM-235 — رد کلید اجرای یکسان با ورودی متفاوت

پیش‌نیاز: منبع کمپین متعلق به میزبان با مجوز و پایان معتبر، سیاست تغییرناپذیر، عضویت ثبت‌شده و پایگاه‌دادهٔ اختصاصی آزمون. ساعت و رسید ثبت قطعی در دادهٔ آزمایشی کنترل می‌شوند؛ زمان دلخواه مرورگر پذیرفته نیست. آزمون مکمل NativeCommitEvidenceTest مرز واقعی PostgreSQL را جدا بررسی می‌کند.

مراحل و انتظار دقیق، از ایجاد داده تا اجرای فرمان و بررسی نتیجه، در بدنهٔ مستقل زیر آمده است. گروه صدعضوی شامل ۷۵ مورد پیش از رزرو، ۱۵ حفاظت‌شده (۵ قرارداد فعال) و ۱۰ پایان‌یافته است؛ سناریوی مجوز، صد عضو فعال و یک مجوز ویرایش لغوشده دارد. کارگرها و قطع فرایند در TM-230 و TM-231 واقعی و مخصوص PostgreSQL هستند و کنارگذاری آن‌ها در SQLite قبولی محسوب نمی‌شود.

اجرا: `php vendor/bin/phpunit --filter TM235Test`؛ برای PostgreSQL متغیر `TM_TEST_DRIVER=pgsql` تنظیم شود. داده و سیاست در `tests/GroupTestCase.php`، سرویس منبع در `tests/Support/HostCampaignProvider.php` و کارگر در `tests/Support/concurrent-group.php` قرار دارند.

```php
public function test_tm235(): void
    {
        [$group] = $this->campaignFixture(); $this->closeCampaign(); $preview = $this->groupService()->previewClosure($this->manager(), $group['group_key']);
        $run = $this->groupService()->executeClosure($this->manager(), $preview, 'same-key');
        self::assertSame($run, $this->groupService()->executeClosure($this->manager(), $preview, 'same-key'));
        $preview['counts']['failed'] = 999;
        try { $this->groupService()->executeClosure($this->manager(), $preview, 'same-key'); self::fail(); }
        catch (DomainError $error) { self::assertSame('idempotency_key_conflict', $error->getMessage()); }
        self::assertSame(1, DB::table('tm_group_operations')->count());
    }
```

فایل اجرایی: `tests/Scenarios/TM235Test.php`. این شاهد توسعهٔ فاز ۳ است و قبولی فاز هفتم تنها پس از توقف تغییرات و اجرای کامل همهٔ شناسه‌ها قابل اعلام است.
