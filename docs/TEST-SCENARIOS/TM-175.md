# TM-175 — دو ارجاع هم‌زمان با یک مقصد

این آزمون مستقل مربوط به فاز ۳ است؛ نتیجهٔ نهایی فاز ۷ محسوب نمی‌شود.

پیش‌نیاز: پایگاه‌دادهٔ اختصاصی آزمون، میزبان آزمایشی با مجوز صریح، ساعت کنترل‌شده و دو مسیر فروش و قرارداد. دادهٔ محرمانه در میزبان می‌ماند.

مراحل و انتظار دقیق در بدنهٔ اجرایی زیر مشخص است. هر فرمان با نسخه و شناسهٔ عملیات اجرا می‌شود؛ نتیجه، وضعیت، تاریخچه یا تعداد اثرها بررسی می‌شود. شکست هر انتظار آزمون را ناموفق می‌کند.

اجرا: `php vendor/bin/phpunit --filter TM175Test`. آزمون هم‌زمانی TM-175 فقط روی PostgreSQL واقعی اجرا می‌شود؛ کنارگذاری آن در SQLite قبولی نیست.

```php
public function test_tm175(): void
    {
        if (DB::connection()->getDriverName() !== 'pgsql') { $this->markTestSkipped('Requires real PostgreSQL handoff concurrency.'); }
        [$origin, $destination, $r] = $this->handoffFixture(false);
        $results = ProcessBarrier::run([
            ['delegate', $origin['instance_key'], $destination['pipeline_key'], $r['id'], 'delegate-one'],
            ['delegate', $origin['instance_key'], $destination['pipeline_key'], $r['id'], 'delegate-two'],
        ], 'concurrent-handoff.php');
        self::assertCount(1, array_filter($results, fn ($result) => ($result['error'] ?? null) === 'version_conflict'));
        self::assertSame(1, DB::table('tm_handoffs')->count()); self::assertSame(2, DB::table('tm_workflow_instances')->count());
        self::assertSame(1, DB::table('tm_outbox')->where('action', 'handoff_created')->count());
    }
```

فایل اجرایی: `tests/Scenarios/TM175Test.php`. پشتیبان داده و سیاست: `tests/HandoffTestCase.php`. برای آزمون حدنصاب، سه مقصد مستقل با سیاست اعلام‌شده ساخته می‌شود؛ برای مسئول، هر سه حالت با دادهٔ جداگانه اجرا می‌شود.
