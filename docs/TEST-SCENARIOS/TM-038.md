# TM-038 — وابستگی بین Scopeها — انتظار: scope_mismatch

فاز مالک: ۴. اجرای فعلی فقط SQLite (پایگاه‌دادهٔ سبک محلی) است؛ آزمون جامع چند پایگاه‌داده به فاز ۷ موکول است.

پیش‌شرط: پایگاه‌دادهٔ اختصاصی تازه، کاربر a و قلمرو one؛ کاربر b/قلمرو two برای آزمون دسترسی. Context (هویت و قلمرو اجرا) صریح است. ساعت در آزمون‌های زمانی ثابت و قابل پیشروی است. هیچ اعلان بیرونی ارسال نمی‌شود.

ورودی، شناسهٔ عملیات، نسخهٔ مورد انتظار، مراحل و بررسی دقیق داده/رویداد/مجوز در بدنهٔ مستقل زیر آمده‌اند؛ اجرای مجدد هر آزمون با بازسازی پایگاه‌داده ایزوله می‌شود.

```php
$a = $this->todo('a'); $other = $this->service()->create($this->manager('a', 'two'), 'other', 'other');
        $this->error('scope_mismatch', fn () => $this->dependencies()->addBatch($this->manager(), [['predecessor' => $a['public_key'], 'predecessor_version' => 1, 'successor' => $other['public_key'], 'successor_version' => 1, 'type' => 'FS', 'policy' => [], 'scope' => 'two']], 'scope'));
        $this->error('not_found', fn () => $this->dependencies()->add($this->manager(), $a['public_key'], 1, $other['public_key'], 1, 'FS', [], 'unknown-reference'));
        self::assertSame(0, DB::table('tm_task_dependencies')->count());
```
