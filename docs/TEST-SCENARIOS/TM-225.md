# TM-225 — بدون تغییر دوبارهٔ مورد پایان‌یافته

پیش‌نیاز: منبع کمپین متعلق به میزبان با مجوز و پایان معتبر، سیاست تغییرناپذیر، عضویت ثبت‌شده و پایگاه‌دادهٔ اختصاصی آزمون. ساعت و رسید ثبت قطعی در دادهٔ آزمایشی کنترل می‌شوند؛ زمان دلخواه مرورگر پذیرفته نیست. آزمون مکمل NativeCommitEvidenceTest مرز واقعی PostgreSQL را جدا بررسی می‌کند.

مراحل و انتظار دقیق، از ایجاد داده تا اجرای فرمان و بررسی نتیجه، در بدنهٔ مستقل زیر آمده است. گروه صدعضوی شامل ۷۵ مورد پیش از رزرو، ۱۵ حفاظت‌شده (۵ قرارداد فعال) و ۱۰ پایان‌یافته است؛ سناریوی مجوز، صد عضو فعال و یک مجوز ویرایش لغوشده دارد. کارگرها و قطع فرایند در TM-230 و TM-231 واقعی و مخصوص PostgreSQL هستند و کنارگذاری آن‌ها در SQLite قبولی محسوب نمی‌شود.

اجرا: `php vendor/bin/phpunit --filter TM225Test`؛ برای PostgreSQL متغیر `TM_TEST_DRIVER=pgsql` تنظیم شود. داده و سیاست در `tests/GroupTestCase.php`، سرویس منبع در `tests/Support/HostCampaignProvider.php` و کارگر در `tests/Support/concurrent-group.php` قرار دارند.

```php
public function test_tm225(): void
    {
        [$group, $instances] = $this->campaignFixture();
        $terminal = $this->instances()->transition($this->manager(), $instances[0]['instance_key'], 1, 'win', 'win'); $this->closeCampaign();
        $transitions = DB::table('tm_instance_transitions')->count();
        $run = $this->groupService()->executeClosure($this->manager(), $this->groupService()->previewClosure($this->manager(), $group['group_key']), 'close');
        self::assertSame(['already_terminal' => 1], $this->processAll($run['run_key'])['counts']); self::assertSame($transitions, DB::table('tm_instance_transitions')->count());
        self::assertSame($terminal['version'], $this->instances()->get($this->manager(), $instances[0]['instance_key'])['version']);
    }
```

فایل اجرایی: `tests/Scenarios/TM225Test.php`. این شاهد توسعهٔ فاز ۳ است و قبولی فاز هفتم تنها پس از توقف تغییرات و اجرای کامل همهٔ شناسه‌ها قابل اعلام است.
