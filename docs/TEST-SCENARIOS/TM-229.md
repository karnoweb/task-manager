# TM-229 — گزارش دلیل و شناسهٔ عملیات هر مورد

پیش‌نیاز: منبع کمپین متعلق به میزبان با مجوز و پایان معتبر، سیاست تغییرناپذیر، عضویت ثبت‌شده و پایگاه‌دادهٔ اختصاصی آزمون. ساعت و رسید ثبت قطعی در دادهٔ آزمایشی کنترل می‌شوند؛ زمان دلخواه مرورگر پذیرفته نیست. آزمون مکمل NativeCommitEvidenceTest مرز واقعی PostgreSQL را جدا بررسی می‌کند.

مراحل و انتظار دقیق، از ایجاد داده تا اجرای فرمان و بررسی نتیجه، در بدنهٔ مستقل زیر آمده است. گروه صدعضوی شامل ۷۵ مورد پیش از رزرو، ۱۵ حفاظت‌شده (۵ قرارداد فعال) و ۱۰ پایان‌یافته است؛ سناریوی مجوز، صد عضو فعال و یک مجوز ویرایش لغوشده دارد. کارگرها و قطع فرایند در TM-230 و TM-231 واقعی و مخصوص PostgreSQL هستند و کنارگذاری آن‌ها در SQLite قبولی محسوب نمی‌شود.

اجرا: `php vendor/bin/phpunit --filter TM229Test`؛ برای PostgreSQL متغیر `TM_TEST_DRIVER=pgsql` تنظیم شود. داده و سیاست در `tests/GroupTestCase.php`، سرویس منبع در `tests/Support/HostCampaignProvider.php` و کارگر در `tests/Support/concurrent-group.php` قرار دارند.

```php
public function test_tm229(): void
    {
        [$group] = $this->campaignFixture(3); $this->closeCampaign();
        $run = $this->groupService()->executeClosure($this->manager(), $this->groupService()->previewClosure($this->manager(), $group['group_key']), 'close'); $this->processAll($run['run_key']);
        $one = $this->groupService()->report($this->manager(), $run['run_key'], 2); $two = $this->groupService()->report($this->manager(), $run['run_key'], 2, $one['next_after_id']);
        self::assertCount(2, $one['items']); self::assertCount(1, $two['items']);
        foreach ([...$one['items'], ...$two['items']] as $item) {
            self::assertSame('campaign_ended', $item['reason_code']); self::assertStringStartsWith('group-item:'.$run['run_key'], $item['operation_id']);
            self::assertSame(1, DB::table('tm_audit_events')->where('action', 'group_item_processed')->where('operation_id', $item['operation_id'])->count());
        }
        self::assertStringNotContainsString('PRIVATE-HOST-TEXT', json_encode([$one, $two]));
        DB::table('host_permissions')->delete(); self::assertSame([], $this->groupService()->report($this->manager(), $run['run_key'])['items']);
        self::assertSame([], $this->groupService()->report($this->manager(), $run['run_key'])['counts']);
    }
```

فایل اجرایی: `tests/Scenarios/TM229Test.php`. این شاهد توسعهٔ فاز ۳ است و قبولی فاز هفتم تنها پس از توقف تغییرات و اجرای کامل همهٔ شناسه‌ها قابل اعلام است.
