# TM-174 — رد نتیجه متناقض

این آزمون مستقل مربوط به فاز ۳ است؛ نتیجهٔ نهایی فاز ۷ محسوب نمی‌شود.

پیش‌نیاز: پایگاه‌دادهٔ اختصاصی آزمون، میزبان آزمایشی با مجوز صریح، ساعت کنترل‌شده و دو مسیر فروش و قرارداد. دادهٔ محرمانه در میزبان می‌ماند.

مراحل و انتظار دقیق در بدنهٔ اجرایی زیر مشخص است. هر فرمان با نسخه و شناسهٔ عملیات اجرا می‌شود؛ نتیجه، وضعیت، تاریخچه یا تعداد اثرها بررسی می‌شود. شکست هر انتظار آزمون را ناموفق می‌کند.

اجرا: `php vendor/bin/phpunit --filter TM174Test`. آزمون هم‌زمانی TM-175 فقط روی PostgreSQL واقعی اجرا می‌شود؛ کنارگذاری آن در SQLite قبولی نیست.

```php
public function test_tm174(): void
    {
        [$h, $origin, $destination] = $this->delegateFixture(false);
        $this->instances()->transition($this->manager(), $destination['instance_key'], 1, 'accept', 'accept');
        $this->handoffs()->settle($this->manager(), $h['handoff_key'], 1, 'return');
        $this->instances()->transition($this->manager(), $destination['instance_key'], 2, 'reopen', 'reopen');
        $this->instances()->transition($this->manager(), $destination['instance_key'], 3, 'reject', 'reject', ['reason_code' => 'invalid']);
        try { $this->handoffs()->settle($this->manager(), $h['handoff_key'], 2, 'contradictory-return'); self::fail(); }
        catch (DomainError $e) { self::assertSame('handoff_already_resolved', $e->getMessage()); }
        self::assertSame('approved', DB::table('tm_handoff_outcomes')->value('outcome'));
        self::assertSame(3, $this->instances()->get($this->manager(), $origin['instance_key'])['version']);
    }
```

فایل اجرایی: `tests/Scenarios/TM174Test.php`. پشتیبان داده و سیاست: `tests/HandoffTestCase.php`. برای آزمون حدنصاب، سه مقصد مستقل با سیاست اعلام‌شده ساخته می‌شود؛ برای مسئول، هر سه حالت با دادهٔ جداگانه اجرا می‌شود.
