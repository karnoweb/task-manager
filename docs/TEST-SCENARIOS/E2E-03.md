# E2E-03 — فروش و تأیید قرارداد

ارجاع فروش به قرارداد با سه تأییدکننده و حد نصاب دو رأی؛ نتیجه‌های تأیید، رد و لغو مستقل بررسی می‌شوند. وضعیت و مسئول مبدأ و ساعت مهلت پس از بازگشت کنترل می‌شود.

سه مجموعه داده مستقل اجرا می‌شوند.

فایل اجرایی: tests/EndToEnd/E2E03Test.php

اجرای مستقل: php vendor/bin/phpunit tests/EndToEnd/E2E03Test.php

شواهد فعلی: docs/phase3-e2e-postgres.xml و گزارش کامل docs/phase3-all-postgres.xml.

این شواهد مربوط به جریان سمت سرور با میزبان آزمایشی واقعی است. تأیید اتصال محصول تجاری و رابط کاربری و پذیرش نهایی فاز هفت جداگانه لازم است.
