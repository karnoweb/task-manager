# TM-186 — رد ارجاع میان دو محدوده

این آزمون مستقل مربوط به فاز ۳ است؛ نتیجهٔ نهایی فاز ۷ محسوب نمی‌شود.

پیش‌نیاز: پایگاه‌دادهٔ اختصاصی آزمون، میزبان آزمایشی با مجوز صریح، ساعت کنترل‌شده و دو مسیر فروش و قرارداد. دادهٔ محرمانه در میزبان می‌ماند.

مراحل و انتظار دقیق در بدنهٔ اجرایی زیر مشخص است. هر فرمان با نسخه و شناسهٔ عملیات اجرا می‌شود؛ نتیجه، وضعیت، تاریخچه یا تعداد اثرها بررسی می‌شود. شکست هر انتظار آزمون را ناموفق می‌کند.

اجرا: `php vendor/bin/phpunit --filter TM186Test`. آزمون هم‌زمانی TM-175 فقط روی PostgreSQL واقعی اجرا می‌شود؛ کنارگذاری آن در SQLite قبولی نیست.

```php
public function test_tm186(): void
    {
        [$origin] = $this->handoffFixture(false); $other = $this->manager(scope: 'two');
        $r = $this->workflows()->publish($other, 'sales', 0, 'other-workflow', $this->definition());
        $p = $this->pipelines()->create($other, 'Other', $r['id'], ['inbox' => ['state' => 'new'], 'review' => ['state' => 'review'], 'won' => ['state' => 'won']], 'other-pipeline');
        try { $this->handoffs()->delegate($this->manager(), $origin['instance_key'], 1, $p['pipeline_key'], $r['id'], 'cross', $this->returnPolicy(), 'cross-scope'); self::fail(); }
        catch (DomainError $e) { self::assertSame('not_found', $e->getMessage()); }
        self::assertSame(0, DB::table('tm_handoffs')->count()); self::assertSame(0, DB::table('tm_process_cases')->count());
        self::assertSame(0, DB::table('tm_case_subjects')->count());
        self::assertSame('active', $this->instances()->get($this->manager(), $origin['instance_key'])['lifecycle']);
    }
```

فایل اجرایی: `tests/Scenarios/TM186Test.php`. پشتیبان داده و سیاست: `tests/HandoffTestCase.php`. برای آزمون حدنصاب، سه مقصد مستقل با سیاست اعلام‌شده ساخته می‌شود؛ برای مسئول، هر سه حالت با دادهٔ جداگانه اجرا می‌شود.
