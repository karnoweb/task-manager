# TM-187 — بازگشت پس از بسته‌شدن مبدأ

این آزمون مستقل مربوط به فاز ۳ است؛ نتیجهٔ نهایی فاز ۷ محسوب نمی‌شود.

پیش‌نیاز: پایگاه‌دادهٔ اختصاصی آزمون، میزبان آزمایشی با مجوز صریح، ساعت کنترل‌شده و دو مسیر فروش و قرارداد. دادهٔ محرمانه در میزبان می‌ماند.

مراحل و انتظار دقیق در بدنهٔ اجرایی زیر مشخص است. هر فرمان با نسخه و شناسهٔ عملیات اجرا می‌شود؛ نتیجه، وضعیت، تاریخچه یا تعداد اثرها بررسی می‌شود. شکست هر انتظار آزمون را ناموفق می‌کند.

اجرا: `php vendor/bin/phpunit --filter TM187Test`. آزمون هم‌زمانی TM-175 فقط روی PostgreSQL واقعی اجرا می‌شود؛ کنارگذاری آن در SQLite قبولی نیست.

```php
public function test_tm187(): void
    {
        [$h, $origin, $destination] = $this->delegateFixture();
        $this->instances()->transition($this->manager(), $origin['instance_key'], 2, 'origin-cancel', 'cancel', ['reason_code' => 'recalled']);
        $this->instances()->transition($this->manager(), $destination['instance_key'], 1, 'destination-success', 'accept');
        $r = $this->handoffs()->settle($this->manager(), $h['handoff_key'], 1, 'return');
        self::assertSame('return_conflict', $r['status']); self::assertSame('approved', $r['outcome']);
        self::assertSame('handoff_return_conflict', $r['failure_code']);
        self::assertSame('cancelled', $this->instances()->get($this->manager(), $origin['instance_key'])['current_state_key']);
    }
```

فایل اجرایی: `tests/Scenarios/TM187Test.php`. پشتیبان داده و سیاست: `tests/HandoffTestCase.php`. برای آزمون حدنصاب، سه مقصد مستقل با سیاست اعلام‌شده ساخته می‌شود؛ برای مسئول، هر سه حالت با دادهٔ جداگانه اجرا می‌شود.
