# E2E-02 — پایان کمپین و بازیابی پس از قطع پردازش

۱۰۰ عضو: ۷۵ شکست با دلیل پایان کمپین، ۱۵ ادامه، ۱۰ پایان‌یافته؛ پنج قرارداد ارجاعی فعال و ۱۲ نقض مهلت مستقل. پردازش فرزند پس از ثبت ۴۰ نتیجه و رزرو ۶۰ مورد واقعاً خاتمه می‌یابد؛ بازیابی فقط پس از انقضای رزرو انجام می‌شود.

این جریان به PostgreSQL و چند پردازش واقعی نیاز دارد؛ روی SQLite صریحاً اجرا نمی‌شود.

فایل اجرایی: tests/EndToEnd/E2E02Test.php

اجرای مستقل: php vendor/bin/phpunit tests/EndToEnd/E2E02Test.php

شواهد فعلی: docs/phase3-e2e-postgres.xml و گزارش کامل docs/phase3-all-postgres.xml.

این شواهد مربوط به جریان سمت سرور با میزبان آزمایشی واقعی است. تأیید اتصال محصول تجاری و رابط کاربری و پذیرش نهایی فاز هفت جداگانه لازم است.
