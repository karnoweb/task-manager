# TM-106 — dependency با تاریخ ناموجود و guard strict به‌جای حدس رد شود

فاز مالک: ۴. اجرای فعلی فقط SQLite (پایگاه‌دادهٔ سبک محلی) است؛ آزمون جامع چند پایگاه‌داده به فاز ۷ موکول است.

پیش‌شرط: پایگاه‌دادهٔ اختصاصی تازه، کاربر a و قلمرو one؛ کاربر b/قلمرو two برای آزمون دسترسی. Context (هویت و قلمرو اجرا) صریح است. ساعت در آزمون‌های زمانی ثابت و قابل پیشروی است. هیچ اعلان بیرونی ارسال نمی‌شود.

ورودی، شناسهٔ عملیات، نسخهٔ مورد انتظار، مراحل و بررسی دقیق داده/رویداد/مجوز در بدنهٔ مستقل زیر آمده‌اند؛ اجرای مجدد هر آزمون با بازسازی پایگاه‌داده ایزوله می‌شود.

```php
$a = $this->todo('a'); $b = $this->todo('b'); $this->link($a, $b);
        $preview = $this->planning()->previewSchedule($this->manager(), $a['public_key'], new \DateTimeImmutable('2026-10-19T08:00:00Z'), new \DateTimeImmutable('2026-10-19T09:00:00Z')); $this->planning()->executeSchedule($this->manager(), $preview, 'plan');
        $b = $this->service()->get($this->manager(), $b['public_key']); $this->error('dependency_date_missing', fn () => $this->service()->mutate($this->manager(), $b['public_key'], $b['version'], 'complete', 'complete'));
```

فایل اجرا: `tests/Scenarios/TM106Test.php`. نتیجه فقط از خروجی اجرای آزمون ثبت می‌شود، نه از وجود فایل.
