# E2E-04 — تیکت و ساخت فرصت فروش

ساخت فرصت از طریق سرویس مالک در همان اتصال؛ دسترسی فروش و مخفی‌ماندن متن خصوصی بررسی می‌شود. سپس سرویس جداگانه پس از ایجاد فرصت پاسخ را از دست می‌دهد؛ تلاش مجدد همان فرصت را بازیابی می‌کند.

سرویس جداگانه از پایگاه SQLite واقعی و مستقل استفاده می‌کند.

فایل اجرایی: tests/EndToEnd/E2E04Test.php

اجرای مستقل: php vendor/bin/phpunit tests/EndToEnd/E2E04Test.php

شواهد فعلی: docs/phase3-e2e-postgres.xml و گزارش کامل docs/phase3-all-postgres.xml.

این شواهد مربوط به جریان سمت سرور با میزبان آزمایشی واقعی است. تأیید اتصال محصول تجاری و رابط کاربری و پذیرش نهایی فاز هفت جداگانه لازم است.
