# TM-236 — اجرای جدید با پیش‌نمایش تازه و تاریخچهٔ مستقل

پیش‌نیاز: منبع کمپین متعلق به میزبان با مجوز و پایان معتبر، سیاست تغییرناپذیر، عضویت ثبت‌شده و پایگاه‌دادهٔ اختصاصی آزمون. ساعت و رسید ثبت قطعی در دادهٔ آزمایشی کنترل می‌شوند؛ زمان دلخواه مرورگر پذیرفته نیست. آزمون مکمل NativeCommitEvidenceTest مرز واقعی PostgreSQL را جدا بررسی می‌کند.

مراحل و انتظار دقیق، از ایجاد داده تا اجرای فرمان و بررسی نتیجه، در بدنهٔ مستقل زیر آمده است. گروه صدعضوی شامل ۷۵ مورد پیش از رزرو، ۱۵ حفاظت‌شده (۵ قرارداد فعال) و ۱۰ پایان‌یافته است؛ سناریوی مجوز، صد عضو فعال و یک مجوز ویرایش لغوشده دارد. کارگرها و قطع فرایند در TM-230 و TM-231 واقعی و مخصوص PostgreSQL هستند و کنارگذاری آن‌ها در SQLite قبولی محسوب نمی‌شود.

اجرا: `php vendor/bin/phpunit --filter TM236Test`؛ برای PostgreSQL متغیر `TM_TEST_DRIVER=pgsql` تنظیم شود. داده و سیاست در `tests/GroupTestCase.php`، سرویس منبع در `tests/Support/HostCampaignProvider.php` و کارگر در `tests/Support/concurrent-group.php` قرار دارند.

```php
public function test_tm236(): void
    {
        [$group] = $this->campaignFixture(3); $this->closeCampaign();
        $first = $this->groupService()->executeClosure($this->manager(), $this->groupService()->previewClosure($this->manager(), $group['group_key']), 'first'); $this->processAll($first['run_key']);
        $transitions = DB::table('tm_instance_transitions')->count(); $preview = $this->groupService()->previewClosure($this->manager(), $group['group_key']);
        self::assertSame(3, $preview['counts']['already_terminal']); $second = $this->groupService()->executeClosure($this->manager(), $preview, 'second');
        self::assertSame(['already_terminal' => 3], $this->processAll($second['run_key'])['counts']); self::assertSame($transitions, DB::table('tm_instance_transitions')->count());
        self::assertSame(2, DB::table('tm_outbox')->where('action', 'group_closure_completed')->count());
        self::assertSame(6, DB::table('tm_outbox')->where('action', 'group_item_processed')->count());
    }
```

فایل اجرایی: `tests/Scenarios/TM236Test.php`. این شاهد توسعهٔ فاز ۳ است و قبولی فاز هفتم تنها پس از توقف تغییرات و اجرای کامل همهٔ شناسه‌ها قابل اعلام است.
