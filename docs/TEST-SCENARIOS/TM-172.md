# TM-172 — تعارض بازگشت پس از تغییر مبدأ

این آزمون مستقل مربوط به فاز ۳ است؛ نتیجهٔ نهایی فاز ۷ محسوب نمی‌شود.

پیش‌نیاز: پایگاه‌دادهٔ اختصاصی آزمون، میزبان آزمایشی با مجوز صریح، ساعت کنترل‌شده و دو مسیر فروش و قرارداد. دادهٔ محرمانه در میزبان می‌ماند.

مراحل و انتظار دقیق در بدنهٔ اجرایی زیر مشخص است. هر فرمان با نسخه و شناسهٔ عملیات اجرا می‌شود؛ نتیجه، وضعیت، تاریخچه یا تعداد اثرها بررسی می‌شود. شکست هر انتظار آزمون را ناموفق می‌کند.

اجرا: `php vendor/bin/phpunit --filter TM172Test`. آزمون هم‌زمانی TM-175 فقط روی PostgreSQL واقعی اجرا می‌شود؛ کنارگذاری آن در SQLite قبولی نیست.

```php
public function test_tm172(): void
    {
        [$h, $origin, $destination] = $this->delegateFixture();
        $changed = $this->instances()->transition($this->manager(), $origin['instance_key'], 2, 'progress', 'progress');
        self::assertSame('waiting', $changed['lifecycle']);
        $this->instances()->transition($this->manager(), $destination['instance_key'], 1, 'accept', 'accept');
        $r = $this->handoffs()->settle($this->manager(), $h['handoff_key'], 1, 'return');
        self::assertSame('return_conflict', $r['status']); self::assertSame('handoff_return_conflict', $r['failure_code']);
        $after = $this->instances()->get($this->manager(), $origin['instance_key']);
        self::assertSame('new', $after['current_state_key']); self::assertSame(3, $after['version']);
        self::assertNotNull($this->sla()->get($this->manager(), $h['paused_visit_id'])['paused_at']);
    }
```

فایل اجرایی: `tests/Scenarios/TM172Test.php`. پشتیبان داده و سیاست: `tests/HandoffTestCase.php`. برای آزمون حدنصاب، سه مقصد مستقل با سیاست اعلام‌شده ساخته می‌شود؛ برای مسئول، هر سه حالت با دادهٔ جداگانه اجرا می‌شود.
