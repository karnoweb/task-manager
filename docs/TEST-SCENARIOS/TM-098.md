# TM-098 — تعریف مستقل گردش‌کار

- پیش‌شرط: پایگاه‌دادهٔ اختصاصی آزمون با ساختار تازه؛ کاربر a در قلمرو one.
- اجرا: فایل متناظر tests/Scenarios/TM098Test.php؛ داده‌ها و شناسه‌های فرمان داخل همان آزمون صریح‌اند.
- مراحل و انتظار: در one و two هرکدام یک کار ساخته می‌شود؛ دو تعریف با شناسه متفاوت باید وجود داشته باشند. تغییر مستقیم دادهٔ آزمون در تعریف one نباید تعریف two را تغییر دهد؛ این تغییر API محصول نیست.
- امنیت: هویت و قلمرو صریح؛ دادهٔ میزبان واقعی ساخته یا تغییر داده نمی‌شود.
- پاک‌سازی: ساخت مجدد ساختار پایگاه‌داده پیش از سناریوی بعدی.
- شواهد: گزارش JUnit در docs؛ وضعیت فقط از اجرای واقعی خوانده شود.
