# TM-043 — تبدیل Item به Task با retry — انتظار: فقط یک Task جدید ساخته شود

فاز مالک: ۴. اجرای فعلی فقط SQLite (پایگاه‌دادهٔ سبک محلی) است؛ آزمون جامع چند پایگاه‌داده به فاز ۷ موکول است.

پیش‌شرط: پایگاه‌دادهٔ اختصاصی تازه، کاربر a و قلمرو one؛ کاربر b/قلمرو two برای آزمون دسترسی. Context (هویت و قلمرو اجرا) صریح است. ساعت در آزمون‌های زمانی ثابت و قابل پیشروی است. هیچ اعلان بیرونی ارسال نمی‌شود.

ورودی، شناسهٔ عملیات، نسخهٔ مورد انتظار، مراحل و بررسی دقیق داده/رویداد/مجوز در بدنهٔ مستقل زیر آمده‌اند؛ اجرای مجدد هر آزمون با بازسازی پایگاه‌داده ایزوله می‌شود.

```php
$task = $this->todo('task'); $list = $this->checklists()->create($this->manager(), $task['public_key'], 'List', 'list');
        $due = new \DateTimeImmutable('2026-10-21T08:00:00Z'); $item = $this->checklists()->addItem($this->manager(), $list['public_key'], 1, 'Convert me', 'a', $due, 'item');
        self::assertSame(1, $this->checklists()->items($this->manager(), $list['public_key'], 'a', $due)['total']); self::assertSame(0, $this->checklists()->items($this->manager(), $list['public_key'], 'b', $due)['total']);
        $this->error('assignee_ineligible', fn () => $this->checklists()->changeItem($this->manager(), $item['public_key'], 1, ['assignee_ref' => 'b'], 'bad-assignee'));
        $converted = $this->checklists()->convert($this->manager(), $item['public_key'], 1, 'convert'); $again = $this->checklists()->convert($this->manager(), $item['public_key'], 1, 'convert');
        self::assertSame($converted['public_key'], $again['public_key']); self::assertSame($task['id'], $converted['parent_task_id']); self::assertSame(2, DB::table('tm_tasks')->count());
        self::assertSame($converted['id'], $this->checklists()->item($this->manager(), $item['public_key'])['converted_task_id']);
```
