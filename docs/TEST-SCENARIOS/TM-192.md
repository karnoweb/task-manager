# TM-192 — سیاست‌های بازگرداندن مسئول

این آزمون مستقل مربوط به فاز ۳ است؛ نتیجهٔ نهایی فاز ۷ محسوب نمی‌شود.

پیش‌نیاز: پایگاه‌دادهٔ اختصاصی آزمون، میزبان آزمایشی با مجوز صریح، ساعت کنترل‌شده و دو مسیر فروش و قرارداد. دادهٔ محرمانه در میزبان می‌ماند.

مراحل و انتظار دقیق در بدنهٔ اجرایی زیر مشخص است. هر فرمان با نسخه و شناسهٔ عملیات اجرا می‌شود؛ نتیجه، وضعیت، تاریخچه یا تعداد اثرها بررسی می‌شود. شکست هر انتظار آزمون را ناموفق می‌کند.

اجرا: `php vendor/bin/phpunit --filter TM192Test`. آزمون هم‌زمانی TM-175 فقط روی PostgreSQL واقعی اجرا می‌شود؛ کنارگذاری آن در SQLite قبولی نیست.

```php
#[\PHPUnit\Framework\Attributes\DataProvider('modes')]
    public function test_tm192(string $mode, string $expected): void
    {
        [$origin, $destination, $r, $pipeline] = $this->handoffFixture(false);
        $this->assignments()->configureStage($this->manager(), $pipeline['pipeline_key'], 'review', 1, 'return-stage-assignment', ['primary' => 'c']);
        $policy = $this->returnPolicy(); $policy['assignment'] = $mode;
        $h = $this->handoffs()->delegate($this->manager(), $origin['instance_key'], 1, $destination['pipeline_key'], $r['id'], 'contracts', $policy, 'delegate');
        $key = DB::table('tm_workflow_instances')->where('id', $h['destination_id'])->value('instance_key');
        $this->assignments()->assign($this->manager(), $key, 1, 'destination-assignee', 'b');
        $this->instances()->transition($this->manager(), $key, 2, 'accept', 'accept');
        self::assertSame('resolved', $this->handoffs()->settle($this->manager(), $h['handoff_key'], 1, 'return')['status']);
        $result = $this->assignments()->get($this->manager(), $origin['instance_key']);
        self::assertSame($expected, $result['primary_assignee']); self::assertSame('a', $result['owner_ref']);
        self::assertSame(1, DB::table('tm_assignment_slots')->where('instance_id', $origin['id'])->where('slot_key', 'primary')->count());
    }
```

فایل اجرایی: `tests/Scenarios/TM192Test.php`. پشتیبان داده و سیاست: `tests/HandoffTestCase.php`. برای آزمون حدنصاب، سه مقصد مستقل با سیاست اعلام‌شده ساخته می‌شود؛ برای مسئول، هر سه حالت با دادهٔ جداگانه اجرا می‌شود.
