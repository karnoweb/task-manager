# TM-227 — پیش‌نمایش و اختلاف بدون تغییر داده

پیش‌نیاز: منبع کمپین متعلق به میزبان با مجوز و پایان معتبر، سیاست تغییرناپذیر، عضویت ثبت‌شده و پایگاه‌دادهٔ اختصاصی آزمون. ساعت و رسید ثبت قطعی در دادهٔ آزمایشی کنترل می‌شوند؛ زمان دلخواه مرورگر پذیرفته نیست. آزمون مکمل NativeCommitEvidenceTest مرز واقعی PostgreSQL را جدا بررسی می‌کند.

مراحل و انتظار دقیق، از ایجاد داده تا اجرای فرمان و بررسی نتیجه، در بدنهٔ مستقل زیر آمده است. گروه صدعضوی شامل ۷۵ مورد پیش از رزرو، ۱۵ حفاظت‌شده (۵ قرارداد فعال) و ۱۰ پایان‌یافته است؛ سناریوی مجوز، صد عضو فعال و یک مجوز ویرایش لغوشده دارد. کارگرها و قطع فرایند در TM-230 و TM-231 واقعی و مخصوص PostgreSQL هستند و کنارگذاری آن‌ها در SQLite قبولی محسوب نمی‌شود.

اجرا: `php vendor/bin/phpunit --filter TM227Test`؛ برای PostgreSQL متغیر `TM_TEST_DRIVER=pgsql` تنظیم شود. داده و سیاست در `tests/GroupTestCase.php`، سرویس منبع در `tests/Support/HostCampaignProvider.php` و کارگر در `tests/Support/concurrent-group.php` قرار دارند.

```php
public function test_tm227(): void
    {
        [$group, $instances] = $this->campaignFixture(); $this->closeCampaign(); $events = DB::table('tm_outbox')->count();
        $preview = $this->groupService()->previewClosure($this->manager(), $group['group_key']);
        self::assertSame($group['policy_id'], $preview['policy_id']); self::assertSame(1, $preview['policy_revision']);
        self::assertSame($events, DB::table('tm_outbox')->count()); self::assertSame(0, DB::table('tm_group_operations')->count());
        $this->instances()->transition($this->manager(), $instances[0]['instance_key'], 1, 'update-stage', 'enter_reservation');
        $events = DB::table('tm_outbox')->count(); $delta = $this->groupService()->previewDelta($this->manager(), $preview);
        self::assertTrue($delta['changed']); self::assertNotSame($preview['member_hash'], $delta['preview']['member_hash']); self::assertSame($events, DB::table('tm_outbox')->count());
        $this->expectExceptionMessage('preview_stale'); $this->groupService()->executeClosure($this->manager(), $preview, 'stale');
    }
```

فایل اجرایی: `tests/Scenarios/TM227Test.php`. این شاهد توسعهٔ فاز ۳ است و قبولی فاز هفتم تنها پس از توقف تغییرات و اجرای کامل همهٔ شناسه‌ها قابل اعلام است.
