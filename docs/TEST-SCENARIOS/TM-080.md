# TM-080 — رد عامل خودکار فاقد دسترسی

- پیش‌شرط: پایگاه‌دادهٔ اختصاصی آزمون با ساختار تازه؛ کاربر a در قلمرو one.
- اجرا: فایل متناظر tests/Scenarios/TM080Test.php؛ داده‌ها و شناسه‌های فرمان داخل همان آزمون صریح‌اند.
- مراحل و انتظار: عامل worker با دسترسی خالی ساخته می‌شود؛ create و count باید capability_denied بدهند. ساخت عامل خودکار بدون فهرست صریح دسترسی نیز باید رد شود.
- امنیت: هویت و قلمرو صریح؛ دادهٔ میزبان واقعی ساخته یا تغییر داده نمی‌شود.
- پاک‌سازی: ساخت مجدد ساختار پایگاه‌داده پیش از سناریوی بعدی.
- شواهد: گزارش JUnit در docs؛ وضعیت فقط از اجرای واقعی خوانده شود.
