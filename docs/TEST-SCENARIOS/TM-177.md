# TM-177 — بازگشت پس از تکمیل همه مقصدها

این آزمون مستقل مربوط به فاز ۳ است؛ نتیجهٔ نهایی فاز ۷ محسوب نمی‌شود.

پیش‌نیاز: پایگاه‌دادهٔ اختصاصی آزمون، میزبان آزمایشی با مجوز صریح، ساعت کنترل‌شده و دو مسیر فروش و قرارداد. دادهٔ محرمانه در میزبان می‌ماند.

مراحل و انتظار دقیق در بدنهٔ اجرایی زیر مشخص است. هر فرمان با نسخه و شناسهٔ عملیات اجرا می‌شود؛ نتیجه، وضعیت، تاریخچه یا تعداد اثرها بررسی می‌شود. شکست هر انتظار آزمون را ناموفق می‌کند.

اجرا: `php vendor/bin/phpunit --filter TM177Test`. آزمون هم‌زمانی TM-175 فقط روی PostgreSQL واقعی اجرا می‌شود؛ کنارگذاری آن در SQLite قبولی نیست.

```php
public function test_tm177(): void
    {
        [$origin, $group] = $this->parallelFixture('all');
        self::assertSame('awaiting_join', $this->complete($group['members'][0], 'one')['status']);
        self::assertSame('waiting', $this->instances()->get($this->manager(), $origin['instance_key'])['lifecycle']);
        self::assertSame('awaiting_join', $this->complete($group['members'][1], 'two')['status']);
        self::assertSame('resolved', $this->complete($group['members'][2], 'three')['status']);
        $result = $this->instances()->get($this->manager(), $origin['instance_key']);
        self::assertSame('review', $result['current_state_key']); self::assertSame(3, $result['version']);
        self::assertSame(3, DB::table('tm_handoff_outcomes')->count()); self::assertSame(0, DB::table('tm_active_handoff_origins')->count());
    }
```

فایل اجرایی: `tests/Scenarios/TM177Test.php`. پشتیبان داده و سیاست: `tests/HandoffTestCase.php`. برای آزمون حدنصاب، سه مقصد مستقل با سیاست اعلام‌شده ساخته می‌شود؛ برای مسئول، هر سه حالت با دادهٔ جداگانه اجرا می‌شود.
