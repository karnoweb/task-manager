# TM-170 — پایان مهلت دقیق و بازاجرای امن

این آزمون مستقل مربوط به فاز ۳ است؛ نتیجهٔ نهایی فاز ۷ محسوب نمی‌شود.

پیش‌نیاز: پایگاه‌دادهٔ اختصاصی آزمون، میزبان آزمایشی با مجوز صریح، ساعت کنترل‌شده و دو مسیر فروش و قرارداد. دادهٔ محرمانه در میزبان می‌ماند.

مراحل و انتظار دقیق در بدنهٔ اجرایی زیر مشخص است. هر فرمان با نسخه و شناسهٔ عملیات اجرا می‌شود؛ نتیجه، وضعیت، تاریخچه یا تعداد اثرها بررسی می‌شود. شکست هر انتظار آزمون را ناموفق می‌کند.

اجرا: `php vendor/bin/phpunit --filter TM170Test`. آزمون هم‌زمانی TM-175 فقط روی PostgreSQL واقعی اجرا می‌شود؛ کنارگذاری آن در SQLite قبولی نیست.

```php
public function test_tm170(): void
    {
        [$h] = $this->delegateFixture();
        try { $this->handoffs()->recall($this->manager(), $h['handoff_key'], 1, 'early-timeout', true); self::fail(); }
        catch (DomainError $e) { self::assertSame('handoff_timeout_not_due', $e->getMessage()); }
        $this->clock->advance('+120 seconds');
        $r = $this->handoffs()->recall($this->manager(), $h['handoff_key'], 1, 'timeout', true);
        self::assertSame('timed_out', $r['outcome']); self::assertSame('resolved', $r['status']);
        self::assertSame($r, $this->handoffs()->recall($this->manager(), $h['handoff_key'], 1, 'timeout', true));
    }
```

فایل اجرایی: `tests/Scenarios/TM170Test.php`. پشتیبان داده و سیاست: `tests/HandoffTestCase.php`. برای آزمون حدنصاب، سه مقصد مستقل با سیاست اعلام‌شده ساخته می‌شود؛ برای مسئول، هر سه حالت با دادهٔ جداگانه اجرا می‌شود.
