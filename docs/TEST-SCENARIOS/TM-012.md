# TM-012 — تعارض محتوای فرمان

- پیش‌شرط: پایگاه‌دادهٔ اختصاصی آزمون با ساختار تازه؛ کاربر a در قلمرو one.
- اجرا: فایل متناظر tests/Scenarios/TM012Test.php؛ داده‌ها و شناسه‌های فرمان داخل همان آزمون صریح‌اند.
- مراحل و انتظار: عنوان اول با شناسه same ساخته می‌شود؛ عنوان دوم با همان شناسه باید idempotency_key_conflict بدهد؛ عنوان اول و یک دفتر فرمان حفظ شوند.
- امنیت: هویت و قلمرو صریح؛ دادهٔ میزبان واقعی ساخته یا تغییر داده نمی‌شود.
- پاک‌سازی: ساخت مجدد ساختار پایگاه‌داده پیش از سناریوی بعدی.
- شواهد: گزارش JUnit در docs؛ وضعیت فقط از اجرای واقعی خوانده شود.
