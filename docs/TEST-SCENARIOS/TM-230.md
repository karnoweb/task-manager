# TM-230 — دو کارگر با واگذاری مستقل و بدون اثر تکراری

پیش‌نیاز: منبع کمپین متعلق به میزبان با مجوز و پایان معتبر، سیاست تغییرناپذیر، عضویت ثبت‌شده و پایگاه‌دادهٔ اختصاصی آزمون. ساعت و رسید ثبت قطعی در دادهٔ آزمایشی کنترل می‌شوند؛ زمان دلخواه مرورگر پذیرفته نیست. آزمون مکمل NativeCommitEvidenceTest مرز واقعی PostgreSQL را جدا بررسی می‌کند.

مراحل و انتظار دقیق، از ایجاد داده تا اجرای فرمان و بررسی نتیجه، در بدنهٔ مستقل زیر آمده است. گروه صدعضوی شامل ۷۵ مورد پیش از رزرو، ۱۵ حفاظت‌شده (۵ قرارداد فعال) و ۱۰ پایان‌یافته است؛ سناریوی مجوز، صد عضو فعال و یک مجوز ویرایش لغوشده دارد. کارگرها و قطع فرایند در TM-230 و TM-231 واقعی و مخصوص PostgreSQL هستند و کنارگذاری آن‌ها در SQLite قبولی محسوب نمی‌شود.

اجرا: `php vendor/bin/phpunit --filter TM230Test`؛ برای PostgreSQL متغیر `TM_TEST_DRIVER=pgsql` تنظیم شود. داده و سیاست در `tests/GroupTestCase.php`، سرویس منبع در `tests/Support/HostCampaignProvider.php` و کارگر در `tests/Support/concurrent-group.php` قرار دارند.

```php
public function test_tm230(): void
    {
        if (DB::connection()->getDriverName() !== 'pgsql') { $this->markTestSkipped('Requires real PostgreSQL group worker row locks.'); }
        [$group] = $this->campaignFixture(100); $this->closeCampaign();
        $run = $this->groupService()->executeClosure($this->manager(), $this->groupService()->previewClosure($this->manager(), $group['group_key']), 'close');
        $results = ProcessBarrier::run([[$run['run_key'], 50], [$run['run_key'], 50]], 'concurrent-group.php');
        self::assertSame([50, 50], array_column($results, 'processed'));
        self::assertSame(['failed' => 100], $this->groupService()->report($this->manager(), $run['run_key'])['counts']);
        self::assertSame(100, DB::table('tm_group_operation_items')->where('attempts', 1)->where('state', 'done')->count());
        self::assertSame(100, DB::table('tm_instance_transitions')->where('to_state', 'failed')->count());
        self::assertSame(100, DB::table('tm_outbox')->where('action', 'group_item_processed')->count());
        self::assertSame(1, DB::table('tm_outbox')->where('action', 'group_closure_completed')->count());
    }
```

فایل اجرایی: `tests/Scenarios/TM230Test.php`. این شاهد توسعهٔ فاز ۳ است و قبولی فاز هفتم تنها پس از توقف تغییرات و اجرای کامل همهٔ شناسه‌ها قابل اعلام است.
