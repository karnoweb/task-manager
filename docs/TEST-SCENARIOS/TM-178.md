# TM-178 — بازگشت با اولین نتیجه مجاز

این آزمون مستقل مربوط به فاز ۳ است؛ نتیجهٔ نهایی فاز ۷ محسوب نمی‌شود.

پیش‌نیاز: پایگاه‌دادهٔ اختصاصی آزمون، میزبان آزمایشی با مجوز صریح، ساعت کنترل‌شده و دو مسیر فروش و قرارداد. دادهٔ محرمانه در میزبان می‌ماند.

مراحل و انتظار دقیق در بدنهٔ اجرایی زیر مشخص است. هر فرمان با نسخه و شناسهٔ عملیات اجرا می‌شود؛ نتیجه، وضعیت، تاریخچه یا تعداد اثرها بررسی می‌شود. شکست هر انتظار آزمون را ناموفق می‌کند.

اجرا: `php vendor/bin/phpunit --filter TM178Test`. آزمون هم‌زمانی TM-175 فقط روی PostgreSQL واقعی اجرا می‌شود؛ کنارگذاری آن در SQLite قبولی نیست.

```php
public function test_tm178(): void
    {
        [$origin, $group] = $this->parallelFixture('any');
        self::assertSame('resolved', $this->complete($group['members'][0], 'one')['status']);
        self::assertSame('detached', $this->handoffs()->get($this->manager(), $group['members'][1]['handoff_key'])['status']);
        self::assertSame('detached_resolved', $this->complete($group['members'][1], 'two')['status']);
        self::assertSame('detached_resolved', $this->complete($group['members'][2], 'three')['status']);
        self::assertSame(3, $this->instances()->get($this->manager(), $origin['instance_key'])['version']);
        self::assertSame(1, DB::table('tm_audit_events')->where('action', 'handoff_returned')->count());
    }
```

فایل اجرایی: `tests/Scenarios/TM178Test.php`. پشتیبان داده و سیاست: `tests/HandoffTestCase.php`. برای آزمون حدنصاب، سه مقصد مستقل با سیاست اعلام‌شده ساخته می‌شود؛ برای مسئول، هر سه حالت با دادهٔ جداگانه اجرا می‌شود.
