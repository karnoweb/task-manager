# TM-147 — تغییر watcher روی اعلان تأثیر بگذارد ولی Permission جدید ایجاد نکند

فاز مالک: ۴. اجرای فعلی فقط SQLite (پایگاه‌دادهٔ سبک محلی) است؛ آزمون جامع چند پایگاه‌داده به فاز ۷ موکول است.

پیش‌شرط: پایگاه‌دادهٔ اختصاصی تازه، کاربر a و قلمرو one؛ کاربر b/قلمرو two برای آزمون دسترسی. Context (هویت و قلمرو اجرا) صریح است. ساعت در آزمون‌های زمانی ثابت و قابل پیشروی است. هیچ اعلان بیرونی ارسال نمی‌شود.

ورودی، شناسهٔ عملیات، نسخهٔ مورد انتظار، مراحل و بررسی دقیق داده/رویداد/مجوز در بدنهٔ مستقل زیر آمده‌اند؛ اجرای مجدد هر آزمون با بازسازی پایگاه‌داده ایزوله می‌شود.

```php
$task = $this->todo('task'); $task = $this->service()->share($this->manager(), $task['public_key'], 1, 'share', 'b');
        $task = $this->collaboration()->watch($this->manager(), $task['public_key'], $task['version'], 'b', true, 'watch');
        self::assertSame(['b'], $this->collaboration()->notificationRecipients($this->manager(), $task['public_key']));
        $task = $this->collaboration()->watch($this->manager(), $task['public_key'], $task['version'], 'b', false, 'unwatch');
        self::assertSame([], $this->collaboration()->notificationRecipients($this->manager(), $task['public_key']));
        $this->service()->share($this->manager(), $task['public_key'], $task['version'], 'revoke', 'b', revoke: true);
        $this->error('not_found', fn () => $this->service()->get($this->manager('b'), $task['public_key']));
        self::assertSame(0, DB::table('tm_task_watchers')->count());
```

فایل اجرا: `tests/Scenarios/TM147Test.php`. نتیجه فقط از خروجی اجرای آزمون ثبت می‌شود، نه از وجود فایل.
