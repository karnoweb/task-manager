# TM-030 — جابه‌جایی والد به فرزند دور — انتظار: چرخه شناسایی شود

فاز مالک: ۴. اجرای فعلی فقط SQLite (پایگاه‌دادهٔ سبک محلی) است؛ آزمون جامع چند پایگاه‌داده به فاز ۷ موکول است.

پیش‌شرط: پایگاه‌دادهٔ اختصاصی تازه، کاربر a و قلمرو one؛ کاربر b/قلمرو two برای آزمون دسترسی. Context (هویت و قلمرو اجرا) صریح است. ساعت در آزمون‌های زمانی ثابت و قابل پیشروی است. هیچ اعلان بیرونی ارسال نمی‌شود.

ورودی، شناسهٔ عملیات، نسخهٔ مورد انتظار، مراحل و بررسی دقیق داده/رویداد/مجوز در بدنهٔ مستقل زیر آمده‌اند؛ اجرای مجدد هر آزمون با بازسازی پایگاه‌داده ایزوله می‌شود.

```php
$a = $this->todo('a'); $b = $this->attach($this->todo('b'), $a, 'b-a'); $c = $this->attach($this->todo('c'), $b, 'c-b');
        $before = DB::table('tm_task_closure')->count();
        $this->error('task_hierarchy_cycle', fn () => $this->hierarchy()->reparent($this->manager(), $a['public_key'], $a['version'], $a['public_key'], $a['version'], 'self'));
        $this->error('task_hierarchy_cycle', fn () => $this->attach($a, $c, 'cycle'));
        self::assertSame($before, DB::table('tm_task_closure')->count()); self::assertNull($this->service()->get($this->manager(), $a['public_key'])['parent_task_id']);
```
