# TM-228 — کهنه‌شدن پیش‌نمایش پس از تغییر عضویت

پیش‌نیاز: منبع کمپین متعلق به میزبان با مجوز و پایان معتبر، سیاست تغییرناپذیر، عضویت ثبت‌شده و پایگاه‌دادهٔ اختصاصی آزمون. ساعت و رسید ثبت قطعی در دادهٔ آزمایشی کنترل می‌شوند؛ زمان دلخواه مرورگر پذیرفته نیست. آزمون مکمل NativeCommitEvidenceTest مرز واقعی PostgreSQL را جدا بررسی می‌کند.

مراحل و انتظار دقیق، از ایجاد داده تا اجرای فرمان و بررسی نتیجه، در بدنهٔ مستقل زیر آمده است. گروه صدعضوی شامل ۷۵ مورد پیش از رزرو، ۱۵ حفاظت‌شده (۵ قرارداد فعال) و ۱۰ پایان‌یافته است؛ سناریوی مجوز، صد عضو فعال و یک مجوز ویرایش لغوشده دارد. کارگرها و قطع فرایند در TM-230 و TM-231 واقعی و مخصوص PostgreSQL هستند و کنارگذاری آن‌ها در SQLite قبولی محسوب نمی‌شود.

اجرا: `php vendor/bin/phpunit --filter TM228Test`؛ برای PostgreSQL متغیر `TM_TEST_DRIVER=pgsql` تنظیم شود. داده و سیاست در `tests/GroupTestCase.php`، سرویس منبع در `tests/Support/HostCampaignProvider.php` و کارگر در `tests/Support/concurrent-group.php` قرار دارند.

```php
public function test_tm228(): void
    {
        [$group, $instances, $pipeline] = $this->campaignFixture(); $this->closeCampaign();
        $preview = $this->groupService()->previewClosure($this->manager(), $group['group_key']);
        $this->host('new-lead'); $added = $this->instances()->start($this->manager(), 'crm.lead', 'new-lead', $instances[0]['workflow_revision_id'], 'new-member', pipelineKey: $pipeline['pipeline_key']);
        $this->groupService()->enroll($this->manager(), $group['group_key'], $group['version'], [['instance_key' => $added['instance_key'], 'version' => 1]], 'add-member');
        try { $this->groupService()->executeClosure($this->manager(), $preview, 'stale'); self::fail(); }
        catch (DomainError $error) { self::assertSame('preview_stale', $error->getMessage()); }
        self::assertSame(0, DB::table('tm_group_operations')->count()); self::assertSame(1, $this->groupService()->previewDelta($this->manager(), $preview)['counts_delta']['failed']);
    }
```

فایل اجرایی: `tests/Scenarios/TM228Test.php`. این شاهد توسعهٔ فاز ۳ است و قبولی فاز هفتم تنها پس از توقف تغییرات و اجرای کامل همهٔ شناسه‌ها قابل اعلام است.
