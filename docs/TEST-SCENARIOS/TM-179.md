# TM-179 — حدنصاب و جلوگیری از بازگشت دوباره

این آزمون مستقل مربوط به فاز ۳ است؛ نتیجهٔ نهایی فاز ۷ محسوب نمی‌شود.

پیش‌نیاز: پایگاه‌دادهٔ اختصاصی آزمون، میزبان آزمایشی با مجوز صریح، ساعت کنترل‌شده و دو مسیر فروش و قرارداد. دادهٔ محرمانه در میزبان می‌ماند.

مراحل و انتظار دقیق در بدنهٔ اجرایی زیر مشخص است. هر فرمان با نسخه و شناسهٔ عملیات اجرا می‌شود؛ نتیجه، وضعیت، تاریخچه یا تعداد اثرها بررسی می‌شود. شکست هر انتظار آزمون را ناموفق می‌کند.

اجرا: `php vendor/bin/phpunit --filter TM179Test`. آزمون هم‌زمانی TM-175 فقط روی PostgreSQL واقعی اجرا می‌شود؛ کنارگذاری آن در SQLite قبولی نیست.

```php
public function test_tm179(): void
    {
        [$origin, $group] = $this->parallelFixture('quorum');
        $first = $this->complete($group['members'][0], 'one');
        self::assertSame('awaiting_join', $first['status']);
        self::assertSame($first, $this->handoffs()->settle($this->manager(), $first['handoff_key'], 2, 'duplicate'));
        self::assertSame('waiting', $this->instances()->get($this->manager(), $origin['instance_key'])['lifecycle']);
        self::assertSame('resolved', $this->complete($group['members'][1], 'two')['status']);
        self::assertSame('detached_resolved', $this->complete($group['members'][2], 'three')['status']);
        self::assertSame(1, DB::table('tm_audit_events')->where('action', 'handoff_returned')->count());
    }
```

فایل اجرایی: `tests/Scenarios/TM179Test.php`. پشتیبان داده و سیاست: `tests/HandoffTestCase.php`. برای آزمون حدنصاب، سه مقصد مستقل با سیاست اعلام‌شده ساخته می‌شود؛ برای مسئول، هر سه حالت با دادهٔ جداگانه اجرا می‌شود.
