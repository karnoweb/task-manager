# TM-173 — نتیجه تکراری بدون اثر دوباره

این آزمون مستقل مربوط به فاز ۳ است؛ نتیجهٔ نهایی فاز ۷ محسوب نمی‌شود.

پیش‌نیاز: پایگاه‌دادهٔ اختصاصی آزمون، میزبان آزمایشی با مجوز صریح، ساعت کنترل‌شده و دو مسیر فروش و قرارداد. دادهٔ محرمانه در میزبان می‌ماند.

مراحل و انتظار دقیق در بدنهٔ اجرایی زیر مشخص است. هر فرمان با نسخه و شناسهٔ عملیات اجرا می‌شود؛ نتیجه، وضعیت، تاریخچه یا تعداد اثرها بررسی می‌شود. شکست هر انتظار آزمون را ناموفق می‌کند.

اجرا: `php vendor/bin/phpunit --filter TM173Test`. آزمون هم‌زمانی TM-175 فقط روی PostgreSQL واقعی اجرا می‌شود؛ کنارگذاری آن در SQLite قبولی نیست.

```php
public function test_tm173(): void
    {
        [$h, $origin, $destination] = $this->delegateFixture();
        $this->clock->advance('+60 seconds');
        $this->instances()->transition($this->manager(), $destination['instance_key'], 1, 'contract-accepted', 'accept');
        $result = $this->handoffs()->settle($this->manager(), $h['handoff_key'], 1, 'return');
        self::assertSame('approved', $result['outcome']); self::assertSame('resolved', $result['status']);
        self::assertSame('review', $this->instances()->get($this->manager(), $origin['instance_key'])['current_state_key']);
        self::assertSame(60, $this->sla()->get($this->manager(), $h['paused_visit_id'])['paused_seconds']);
        $count = DB::table('tm_audit_events')->count();
        self::assertSame($result, $this->handoffs()->settle($this->manager(), $h['handoff_key'], 1, 'return'));
        self::assertSame($result, $this->handoffs()->settle($this->manager(), $h['handoff_key'], 2, 'duplicate-return'));
        self::assertSame($count, DB::table('tm_audit_events')->count());
    }
```

فایل اجرایی: `tests/Scenarios/TM173Test.php`. پشتیبان داده و سیاست: `tests/HandoffTestCase.php`. برای آزمون حدنصاب، سه مقصد مستقل با سیاست اعلام‌شده ساخته می‌شود؛ برای مسئول، هر سه حالت با دادهٔ جداگانه اجرا می‌شود.
