# TM-037 — race در افزودن دو dependency — انتظار: یک تغییر معتبر و graph بدون چرخه

فاز مالک: ۴. آزمون فعلی SQLite (پایگاه‌دادهٔ سبک محلی) رفتار ترتیبی، کنترل نسخه و حفظ ساختار را می‌سنجد. رقابت واقعی چند اتصال روی MySQL/PostgreSQL طبق درخواست کاربر به فاز ۷ موکول است.

پیش‌شرط: پایگاه‌دادهٔ اختصاصی تازه، کاربر a و قلمرو one؛ کاربر b/قلمرو two برای آزمون دسترسی. Context (هویت و قلمرو اجرا) صریح است. ساعت در آزمون‌های زمانی ثابت و قابل پیشروی است. هیچ اعلان بیرونی ارسال نمی‌شود.

ورودی، شناسهٔ عملیات، نسخهٔ مورد انتظار، مراحل و بررسی دقیق داده/رویداد/مجوز در بدنهٔ مستقل زیر آمده‌اند؛ اجرای مجدد هر آزمون با بازسازی پایگاه‌داده ایزوله می‌شود.

```php
$a = $this->todo('a'); $b = $this->todo('b'); $this->link($a, $b, operation: 'first-client');
        $this->error('version_conflict', fn () => $this->dependencies()->add($this->manager(), $b['public_key'], 1, $a['public_key'], 1, 'FS', [], 'stale-client'));
        $this->error('dependency_cycle', fn () => $this->link($b, $a, operation: 'fresh-reverse'));
        self::assertSame(1, DB::table('tm_task_dependencies')->whereNull('deleted_at')->count()); self::assertSame(1, DB::table('tm_active_dependencies')->count());
```
