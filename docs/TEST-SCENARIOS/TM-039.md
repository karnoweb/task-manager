# TM-039 — related link بدون Block — انتظار: انتقال مجاز طبق Workflow

فاز مالک: ۴. اجرای فعلی فقط SQLite (پایگاه‌دادهٔ سبک محلی) است؛ آزمون جامع چند پایگاه‌داده به فاز ۷ موکول است.

پیش‌شرط: پایگاه‌دادهٔ اختصاصی تازه، کاربر a و قلمرو one؛ کاربر b/قلمرو two برای آزمون دسترسی. Context (هویت و قلمرو اجرا) صریح است. ساعت در آزمون‌های زمانی ثابت و قابل پیشروی است. هیچ اعلان بیرونی ارسال نمی‌شود.

ورودی، شناسهٔ عملیات، نسخهٔ مورد انتظار، مراحل و بررسی دقیق داده/رویداد/مجوز در بدنهٔ مستقل زیر آمده‌اند؛ اجرای مجدد هر آزمون با بازسازی پایگاه‌داده ایزوله می‌شود.

```php
$a = $this->todo('a'); $b = $this->todo('b'); $link = $this->link($a, $b, 'relates_to');
        self::assertSame('done', $this->service()->mutate($this->manager(), $b['public_key'], 2, 'complete-b', 'complete')['state']);
        $b = $this->service()->get($this->manager(), $b['public_key']); $this->service()->share($this->manager(), $b['public_key'], $b['version'], 'share-b', 'b');
        self::assertSame(0, $this->dependencies()->links($this->manager('b'), $b['public_key'])['total']);
        $this->error('not_found', fn () => $this->dependencies()->get($this->manager('b'), $link['public_key']));
        self::assertSame(1, $this->dependencies()->links($this->manager(), $b['public_key'])['total']);
```
