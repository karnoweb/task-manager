# TM-107 — cross-project در یک Scope با مجوز دوطرفه و cross-scope همیشه رد شود

فاز مالک: ۴. اجرای فعلی فقط SQLite (پایگاه‌دادهٔ سبک محلی) است؛ آزمون جامع چند پایگاه‌داده به فاز ۷ موکول است.

پیش‌شرط: پایگاه‌دادهٔ اختصاصی تازه، کاربر a و قلمرو one؛ کاربر b/قلمرو two برای آزمون دسترسی. Context (هویت و قلمرو اجرا) صریح است. ساعت در آزمون‌های زمانی ثابت و قابل پیشروی است. هیچ اعلان بیرونی ارسال نمی‌شود.

ورودی، شناسهٔ عملیات، نسخهٔ مورد انتظار، مراحل و بررسی دقیق داده/رویداد/مجوز در بدنهٔ مستقل زیر آمده‌اند؛ اجرای مجدد هر آزمون با بازسازی پایگاه‌داده ایزوله می‌شود.

```php
[$revision, $project, $a] = $this->projectTask(); $other = $this->projects()->create($this->manager(), 'OTHER', 'Other', $revision['id'], 'other'); $b = $this->inProject($other, 'other-task');
        $this->projects()->change($this->manager(), $project['project_key'], 1, 'member-b', 'member', ['actor' => 'b', 'role' => 'member']);
        $this->error('not_found', fn () => $this->dependencies()->add($this->manager('b'), $a['public_key'], $a['version'], $b['public_key'], $b['version'], 'FS', [], 'limited'));
        $link = $this->link($a, $b); self::assertSame('FS', $link['type']); self::assertSame(1, DB::table('tm_task_dependencies')->count());
```
