# TM-003 — تکمیل و بازگشایی

- پیش‌شرط: پایگاه‌دادهٔ اختصاصی آزمون با ساختار تازه؛ کاربر a در قلمرو one.
- اجرا: فایل متناظر tests/Scenarios/TM003Test.php؛ داده‌ها و شناسه‌های فرمان داخل همان آزمون صریح‌اند.
- مراحل و انتظار: پس از ایجاد، فرمان done در نسخه ۱ اجرا می‌شود؛ حالت done و زمان تکمیل بررسی می‌شوند. سپس فرمان open در نسخه ۲ باید حالت pending و زمان خالی بسازد؛ دو انتقال تاریخی حفظ شوند.
- امنیت: هویت و قلمرو صریح؛ دادهٔ میزبان واقعی ساخته یا تغییر داده نمی‌شود.
- پاک‌سازی: ساخت مجدد ساختار پایگاه‌داده پیش از سناریوی بعدی.
- شواهد: گزارش JUnit در docs؛ وضعیت فقط از اجرای واقعی خوانده شود.
