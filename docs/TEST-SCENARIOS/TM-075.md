# TM-075 — Authorization در Bulk — انتظار: atomic یا partial طبق mode، بدون bypass

فاز مالک: ۴. اجرای فعلی فقط SQLite (پایگاه‌دادهٔ سبک محلی) است؛ آزمون جامع چند پایگاه‌داده به فاز ۷ موکول است.

پیش‌شرط: پایگاه‌دادهٔ اختصاصی تازه، کاربر a و قلمرو one؛ کاربر b/قلمرو two برای آزمون دسترسی. Context (هویت و قلمرو اجرا) صریح است. ساعت در آزمون‌های زمانی ثابت و قابل پیشروی است. هیچ اعلان بیرونی ارسال نمی‌شود.

ورودی، شناسهٔ عملیات، نسخهٔ مورد انتظار، مراحل و بررسی دقیق داده/رویداد/مجوز در بدنهٔ مستقل زیر آمده‌اند؛ اجرای مجدد هر آزمون با بازسازی پایگاه‌داده ایزوله می‌شود.

```php
$a = $this->todo('a'); $b = $this->service()->create($this->manager('b'), 'Private', 'private'); $bulk = $this->app->make(BulkService::class);
        $items = [['task_key' => $a['public_key'], 'version' => 1, 'action' => 'complete'], ['task_key' => $b['public_key'], 'version' => 1, 'action' => 'complete']]; $before = DB::table('tm_outbox')->count();
        $this->error('not_found', fn () => $bulk->execute($this->manager(), $items, 'atomic', 'atomic')); self::assertSame('pending', $this->service()->get($this->manager(), $a['public_key'])['state']); self::assertSame($before, DB::table('tm_outbox')->count());
        $result = $bulk->execute($this->manager(), $items, 'partial', 'partial'); self::assertSame('completed', $result['items'][0]['status']); self::assertSame('not_found', $result['items'][1]['reason_code']);
        self::assertArrayNotHasKey('task_key', $result['items'][1]); self::assertSame('done', $this->service()->get($this->manager(), $a['public_key'])['state']);
        self::assertSame($result, $bulk->execute($this->manager(), $items, 'partial', 'partial')); self::assertSame(2, $this->service()->get($this->manager(), $a['public_key'])['version']);
```

فایل اجرا: `tests/Scenarios/TM075Test.php`. نتیجه فقط از خروجی اجرای آزمون ثبت می‌شود، نه از وجود فایل.
