# TM-011 — تکرار همان فرمان

- پیش‌شرط: پایگاه‌دادهٔ اختصاصی آزمون با ساختار تازه؛ کاربر a در قلمرو one.
- اجرا: فایل متناظر tests/Scenarios/TM011Test.php؛ داده‌ها و شناسه‌های فرمان داخل همان آزمون صریح‌اند.
- مراحل و انتظار: دو درخواست با عنوان و شناسه create یکسان اجرا می‌شوند؛ پاسخ‌ها باید دقیقاً برابر و تعداد کار، دفتر فرمان و رویداد خروجی هرکدام یک باشد.
- امنیت: هویت و قلمرو صریح؛ دادهٔ میزبان واقعی ساخته یا تغییر داده نمی‌شود.
- پاک‌سازی: ساخت مجدد ساختار پایگاه‌داده پیش از سناریوی بعدی.
- شواهد: گزارش JUnit در docs؛ وضعیت فقط از اجرای واقعی خوانده شود.
