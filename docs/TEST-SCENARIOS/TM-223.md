# TM-223 — ادامه با رویداد ثبت قطعی در یا پیش از مرز

پیش‌نیاز: منبع کمپین متعلق به میزبان با مجوز و پایان معتبر، سیاست تغییرناپذیر، عضویت ثبت‌شده و پایگاه‌دادهٔ اختصاصی آزمون. ساعت و رسید ثبت قطعی در دادهٔ آزمایشی کنترل می‌شوند؛ زمان دلخواه مرورگر پذیرفته نیست. آزمون مکمل NativeCommitEvidenceTest مرز واقعی PostgreSQL را جدا بررسی می‌کند.

مراحل و انتظار دقیق، از ایجاد داده تا اجرای فرمان و بررسی نتیجه، در بدنهٔ مستقل زیر آمده است. گروه صدعضوی شامل ۷۵ مورد پیش از رزرو، ۱۵ حفاظت‌شده (۵ قرارداد فعال) و ۱۰ پایان‌یافته است؛ سناریوی مجوز، صد عضو فعال و یک مجوز ویرایش لغوشده دارد. کارگرها و قطع فرایند در TM-230 و TM-231 واقعی و مخصوص PostgreSQL هستند و کنارگذاری آن‌ها در SQLite قبولی محسوب نمی‌شود.

اجرا: `php vendor/bin/phpunit --filter TM223Test`؛ برای PostgreSQL متغیر `TM_TEST_DRIVER=pgsql` تنظیم شود. داده و سیاست در `tests/GroupTestCase.php`، سرویس منبع در `tests/Support/HostCampaignProvider.php` و کارگر در `tests/Support/concurrent-group.php` قرار دارند.

```php
public function test_tm223(): void
    {
        [$group, $instances] = $this->campaignFixture(); $this->reserve($instances[0], 'one'); $this->closeCampaign();
        $preview = $this->groupService()->previewClosure($this->manager(), $group['group_key']); self::assertSame(1, $preview['counts']['continued']);
        $run = $this->groupService()->executeClosure($this->manager(), $preview, 'close');
        self::assertSame(['continued' => 1], $this->processAll($run['run_key'])['counts']);
        self::assertSame('reservation', $this->instances()->get($this->manager(), $instances[0]['instance_key'])['current_state_key']);
    }
```

فایل اجرایی: `tests/Scenarios/TM223Test.php`. این شاهد توسعهٔ فاز ۳ است و قبولی فاز هفتم تنها پس از توقف تغییرات و اجرای کامل همهٔ شناسه‌ها قابل اعلام است.
